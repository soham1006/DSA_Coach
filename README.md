# DSA_Coach

DSA_Coach is an AI-powered interactive learning tool designed to help students understand Data Structures and Algorithms through clear explanations, code, and visual step-by-step execution.

## What it does

- Explains DSA problems in beginner-friendly language
- Shows multiple approaches with time and space complexity
- Generates code in the selected programming language
- Breaks the solution into step-by-step execution states
- Provides visual representations for arrays, graphs, trees, stacks, queues, linked lists, and DP
- Accepts only DSA-related questions

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Node.js + Express
- Google Gemini API
- Zod
